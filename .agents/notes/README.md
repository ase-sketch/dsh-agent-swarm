# 决策笔记规范

落在 `.agents/notes/{lifecycle}/{class}/YYYY-MM-DD-slug.md`：lifecycle = proposed / implemented / rejected / archived；class = feature / bug-fix / simplification / architecture / process / testing（封闭六类）。
模板五段：Problem / Decision / Alternatives considered（必填，每个备选一段+落败原因）/ Consequences / Confirmation。
纪律：笔记与代码同一提交；禁止集中索引（目录树即索引）；一事一处；演进时更新归属笔记而非新建。
